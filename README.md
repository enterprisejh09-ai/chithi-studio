# Chithi Studio — Digital Letter Website

A responsive bilingual (Bangla + English) letter-writing website. Choose a category, personalize the message, preview the letter inside an envelope, open it with an animation, then copy, download, or share the letter through WhatsApp.

## Included categories
- Personal Letter
- Love Letter
- Invitation Letter
- Birthday Letter
- Thank You Letter
- Apology Letter
- Friendship Letter
- Custom Letter

## Run locally
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. No npm install or build command is required.

## Publish on GitHub Pages
1. Create a GitHub repository and upload all files to the repository root.
2. Go to Settings → Pages.
3. Select Deploy from a branch, choose `main` and `/ (root)`, then Save.
4. Wait for GitHub Pages to publish the website.

## Publish on Vercel
Import the repository into Vercel. Select the Other framework preset; no build command is required and the output directory is `.`.

## Notes
- The letter is composed in the browser. This static starter does not send email or store letters on a server.
- Copy, TXT download and WhatsApp sharing are supported.
- Edit the templates in `app.js` to change the default wording and add more categories.
